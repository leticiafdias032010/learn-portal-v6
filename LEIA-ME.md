# Learn by L. D. — guia rápido
O banco (Supabase) e a função de e-mails já estão configurados. Falta só publicar estes arquivos (Netlify Drop ou Vercel).

Depois de publicar:
1. Supabase → Authentication → URL Configuration: coloque o endereço do site em "Site URL" e em "Redirect URLs".
2. Cadastre-se no site com ldprojectcontact@gmail.com e confirme o e-mail: a conta vira admin sozinha. Mantenha "Confirm email" LIGADO.
3. Painel Admin → "Configurações": confira contato, chaves PIX, previsão de dias e o endereço do site.
4. E-mails automáticos (opcional): Painel Admin → "Administradores e e-mails". Sem isso, os avisos continuam no sino do site.
5. Gerador: cole sua chave do Google AI Studio no Painel Admin (fica só no seu navegador).

Mudanças do dia a dia (contato, PIX, áreas novas, admins, etapas, extras) são feitas no Painel Admin e valem na hora. Só mudanças de código exigem republicar os arquivos.
